These static faces use the upstream Text optical size and Friendly roundness 50.
The app bundles its four interface weights and their true obliques so native
weight and italic selection preserve text emphasis. Each app and extension
bundles this directory.

AppTypography enables ss01 and ss02 at runtime. It leaves ss03 off and disables
contextual arrow and fraction substitutions so literal text stays literal.
